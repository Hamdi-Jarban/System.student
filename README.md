
# System Student

نظام إدارة طلاب وموظفين مبني باستخدام C++.

## الوصف
هذا المشروع هو نسخة C++ من نظام إدارة الطلاب والموظفين الذي كان موجودًا داخل ملف README سابقًا. يتيح النظام إدارة البيانات الأساسية للطلاب والموظفين، مع دعم عمليات العرض، البحث، والإحصائيات.

## المميزات
- إضافة طالب
- إضافة موظف
- عرض الطلاب
- عرض الموظفين
- البحث عن بيانات طالب
- عرض الإحصائيات
- حساب المتبقي والمدفوع
- إدارة الغرف

## التشغيل
استخدم مترجم C++ مثل g++:

```bash
g++ main.cpp -o student_system
./student_system
```
